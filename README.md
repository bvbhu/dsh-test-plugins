# dsh-pixmax-workflow

AI 视频生成工作流 bundle：生图/改图、ffmpeg 视频解析、Pixmax CLI 零积分操作 —— 7 个工具 + 自带预设 + 设置页。

```sh
dsh plugin --profile <name> add github:bvbhu/dsh-test-plugins#dsh-pixmax-workflow
```

工具只注册给自带预设「AI 视频工作流」；主行 `dsh-pixmax-workflow` **不要关**（设置页与 HTTP 桥挂在它上面）。

详细说明与**公开范围**见 [DETAILS.md](DETAILS.md)。
